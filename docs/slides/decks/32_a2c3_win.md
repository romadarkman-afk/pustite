# Половодье: победа

- **Файлы:** `a2c3_win/01 … 04` (формат подписан у каждой картинки)
- **Где показывается:** После победы в главе «Половодье»
- **Настроение:** Усталое облегчение. Музыка: светлая, рассвет.
- **Свет и цвет колоды:** blue dawn, hoarfrost on logs, first rose-gold light
- **Картинок:** 4, из них волна 1: 2

Один чат ChatGPT на колоду. В начало чата приложите листы-эталоны персонажей колоды и (если есть) эталон места, вставьте блок «Стиль» из `00_style.md`, потом идите по картинкам сверху вниз.
