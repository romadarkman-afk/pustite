# Список: вход

- **Файлы:** `a4c2_intro/01 … 05` (формат подписан у каждой картинки)
- **Где показывается:** Перед главой «Список» (Грузовой Тупик, весна, угольный туман)
- **Настроение:** Нарастающая тревога. Музыка: ночная или тревожная.
- **Свет и цвет колоды:** coal-dust mist: black and sulphur-yellow, cold steel, orange forge glow, grimy faces
- **Картинок:** 5, из них волна 1: 3

Один чат ChatGPT на колоду. В начало чата приложите листы-эталоны персонажей колоды и (если есть) эталон места, вставьте блок «Стиль» из `00_style.md`, потом идите по картинкам сверху вниз.

**Лица в этой колоде:** Аркадий (`cast_pisar.png`), Смотритель (`cast_smotritel.png`)
