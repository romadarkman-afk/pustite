# Брод: вход

- **Файлы:** `a2c1_intro/01 … 05` (формат подписан у каждой картинки)
- **Где показывается:** Перед главой «Брод» (Мельничный Двор, осень, ливень)
- **Настроение:** Нарастающая тревога. Музыка: ночная или тревожная.
- **Свет и цвет колоды:** autumn deluge: slate grey and rust, wet shine, lanterns dying one by one, the mill a dark mass
- **Картинок:** 5, из них волна 1: 3

Один чат ChatGPT на колоду. В начало чата приложите листы-эталоны персонажей колоды и (если есть) эталон места, вставьте блок «Стиль» из `00_style.md`, потом идите по картинкам сверху вниз.

**Лица в этой колоде:** Мельник Савелий (`cast_melnik.png`)
