# Колокол: вход

- **Файлы:** `a3c2_intro/01 … 05` (формат подписан у каждой картинки)
- **Где показывается:** Перед главой «Колокол» (Монастырский Двор, зима, снегопад)
- **Настроение:** Нарастающая тревога. Музыка: ночная или тревожная.
- **Свет и цвет колоды:** heavy snowfall, cold blue-grey, orange candlelight in windows, cathedral gold glints
- **Картинок:** 5, из них волна 1: 3

Один чат ChatGPT на колоду. В начало чата приложите листы-эталоны персонажей колоды и (если есть) эталон места, вставьте блок «Стиль» из `00_style.md`, потом идите по картинкам сверху вниз.

**Лица в этой колоде:** Брат Игнат (`cast_ignat.png`)
