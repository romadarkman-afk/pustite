# Ворота: вход

- **Файлы:** `a3c1_intro/01 … 05` (формат подписан у каждой картинки)
- **Где показывается:** Перед главой «Ворота» (Внешний Скит, зима, метель)
- **Настроение:** Нарастающая тревога. Музыка: ночная или тревожная.
- **Свет и цвет колоды:** winter blizzard: blue-white snow, black timber, orange window lights, breath fog
- **Картинок:** 5, из них волна 1: 3

Один чат ChatGPT на колоду. В начало чата приложите листы-эталоны персонажей колоды и (если есть) эталон места, вставьте блок «Стиль» из `00_style.md`, потом идите по картинкам сверху вниз.

**Лица в этой колоде:** Сестра Анфиса (`cast_anfisa.png`), Агафья (`cast_agafya.png`)
