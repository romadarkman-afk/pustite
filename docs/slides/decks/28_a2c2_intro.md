# Чужаки: вход

- **Файлы:** `a2c2_intro/01 … 05` (формат подписан у каждой картинки)
- **Где показывается:** Перед главой «Чужаки» (Затопленная Слобода, осень, наводнение)
- **Настроение:** Нарастающая тревога. Музыка: ночная или тревожная.
- **Свет и цвет колоды:** autumn flood: flat brown-grey water, reflected lantern lights, mist, rust-coloured roofs
- **Картинок:** 5, из них волна 1: 3

Один чат ChatGPT на колоду. В начало чата приложите листы-эталоны персонажей колоды и (если есть) эталон места, вставьте блок «Стиль» из `00_style.md`, потом идите по картинкам сверху вниз.

**Лица в этой колоде:** Гордей (`cast_gordey.png`), Агафья (`cast_agafya.png`), Ефим (`cast_efim.png`)
