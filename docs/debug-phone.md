# Отладка на телефоне (TASK-096)

Для Влади, Windows. Что получится: экран телефона на ПК, APK из CI ставится одной командой, при вылете есть журнал, который можно прислать. Отладочное меню в игре даёт счётчик кадров и переход в любую главу.

## 1. Один раз поставить программы

В PowerShell:

```
winget install Genymobile.scrcpy
```

В пакет входит `adb`. Если `winget` нет: скачать `scrcpy-win64-*.zip` со страницы <https://github.com/Genymobile/scrcpy/releases>, распаковать в `C:\scrcpy`, открывать PowerShell в этой папке.

Проверка: `adb version` и `scrcpy --version` выводят версии. Если пишет «не распознано», закрыть и открыть PowerShell заново.

## 2. Включить отладку на телефоне

1. Настройки, «О телефоне», 7 раз тапнуть по «Номер сборки» (на Xiaomi по «Версия MIUI/HyperOS»). Появится «Для разработчиков».
2. «Для разработчиков», включить «Отладка по USB».
3. Xiaomi и Redmi: там же включить «Установка через USB» и «Отладка по USB (настройки безопасности)». Без этого `adb install` падает с ошибкой.
4. Подключить телефон кабелем к ПК, режим USB «Передача файлов». На телефоне появится вопрос «Разрешить отладку по USB?», поставить «Всегда разрешать с этого компьютера».
5. `adb devices` должен показать строку со словом `device`. Если `unauthorized`, не нажат вопрос на телефоне. Если список пуст, сменить кабель (часть кабелей только заряжает) или порт.

Без кабеля (Android 11 и новее): «Для разработчиков», «Беспроводная отладка», «Сопрягать с кодом». Затем `adb pair IP:порт` с кодом из окошка, потом `adb connect IP:порт` с адресом с главного экрана раздела. Телефон и ПК в одной сети Wi-Fi.

## 3. Показать экран телефона на ПК

```
scrcpy --stay-awake --max-size 1280
```

Окно можно тапать мышью. Запись видео: `scrcpy --record=pustite.mp4`. Остановить: закрыть окно. Если картинка тормозит, добавить `--max-fps 30`: это ограничит только трансляцию, игра идёт на полной скорости.

Видео с жестами и счётчиком кадров лучше всего описывает проблему: приложить его к сообщению.

## 4. Поставить свежий APK из CI

1. GitHub, репозиторий `romadarkman-afk/pustite`, вкладка Actions, запуск «Сборка APK» с зелёной галочкой.
2. Внизу страницы запуска раздел Artifacts, скачать `pustite-apk` (zip), распаковать.
3. В PowerShell из папки с файлом:

```
adb install -r pustite.apk
```

`-r` ставит поверх, сохранение остаётся. Подпись у сборок CI одна и та же (ключ лежит в кэше CI), поэтому обновление поверх работает. Если пишет `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, стоит другая сборка с иной подписью: `adb uninstall com.vladi.pustite` и поставить заново (сохранение пропадёт).

Запустить с ПК: `adb shell monkey -p com.vladi.pustite 1`.

Время запуска (для замера): `adb shell am start -W -n com.vladi.pustite/com.godot.game.GodotApp`. Строка `TotalTime` это миллисекунды от тапа до первого кадра. Перед замером остановить игру: `adb shell am force-stop com.vladi.pustite`. Если имя активности не подошло: `adb shell cmd package resolve-activity --brief com.vladi.pustite`.

## 5. Журнал при вылете

Перед воспроизведением очистить буфер, потом повторить вылет и сразу сохранить:

```
adb logcat -c
(повторить вылет на телефоне)
adb logcat -d -v time godot:V AndroidRuntime:E DEBUG:V libc:E *:S > pustite-log.txt
```

Файл `pustite-log.txt` прислать целиком. В нём видно последние сообщения движка (`godot`), падение Java (`AndroidRuntime`) и нативное падение (`DEBUG`, `libc`).

Если вылет произошёл давно и буфер успел затереться, сохранить всё, что есть: `adb logcat -d > pustite-full.txt`. Файл большой, но содержит всё.

Игра сама пишет «хлебные крошки» (последние шаги перед вылетом) и после аварии показывает экран отчёта с текстом: его можно скопировать и прислать вместо журнала, если ПК под рукой нет. Журнал движка внутри телефона: `adb shell run-as com.vladi.pustite find . -name godot.log`, затем `adb shell run-as com.vladi.pustite cat <найденный путь>`. `run-as` работает только с отладочной сборкой, то есть с APK из CI.

## 6. Скрытое отладочное меню в игре

Только в отладочной сборке (APK из CI). В магазинной сборке меню нет.

1. Главный экран, «Настройки», прокрутить вниз до строки версии (серая `v0.62.0`).
2. Пять быстрых тапов подряд за три секунды.
3. Откроется экран «Отладка»:
   - переключатель счётчика кадров (в углу `FPS 58  мин 41`: первое число за последнюю секунду, второе худшая секунда на текущем экране);
   - живые цифры: модель телефона, видеочип, узлы, объекты, вызовы отрисовки, память картинок и видео, режим упрощённой графики; обновляются дважды в секунду;
   - 12 кнопок «Перейти к главе»: запускают любую главу без прохождения предыдущих.

Прыжок в главу сохраняет результат как обычная игра: звёзды, погибшие, достижения. Чтобы не портить основное сохранение, перед проверками поздних глав стоит играть на отдельной установке (`adb uninstall`, затем свежий APK) или заранее сделать копию: `adb shell run-as com.vladi.pustite cp -r files /sdcard/Download/pustite-backup` (путь может отличаться, смотри раздел 5).

## 7. Замер кадров для docs/budget.md

Таблица в разделе TASK-070 ждёт цифры. Порядок для каждой строки:

1. Настройки, вкладка «Экран»: выключить «Упрощённую графику». Включить счётчик кадров в меню «Отладка».
2. Меню «Отладка», глава из таблицы: `a1c3` (лето, дождь), `a2c1` (осень), `a3c1` (зима, метель), `a4c1` (весна, туман).
3. Пройти вступление, дойти до второго дня. На экране дня 30 секунд походить по посёлку и записать `мин`.
4. Закончить день, на ночном экране двери подождать 30 секунд и записать `мин`.
5. Повторить с включённой упрощённой графикой.
6. Написать мне модель телефона и восемь чисел (по два на карту и режим).

Память одной командой с ПК, пока игра открыта на ночной карте:

```
adb shell dumpsys meminfo com.vladi.pustite
```

Нужны строки `TOTAL PSS` и `Graphics`. Ориентир по расчётам: картинки на ночных картах занимают 135–158 МиБ видеопамяти (`docs/budget.md`, TASK-095), всё приложение вместе с движком обычно 400–600 МиБ. Выше 800 МиБ на телефоне с 3 ГБ памяти опасно: система начнёт закрывать приложение в фоне.

Кадры с точки зрения системы (если счётчик игры вызывает вопросы):

```
adb shell dumpsys gfxinfo com.vladi.pustite reset
(10 секунд поиграть)
adb shell dumpsys gfxinfo com.vladi.pustite
```

Нужны `Janky frames` и перцентили `90th`, `95th`, `99th` по времени кадра. Для 60 кадров в секунду кадр должен укладываться в 16 мс.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `adb devices` пусто | другой кабель или порт, режим USB «Передача файлов», переоткрыть «Отладку по USB» |
| `unauthorized` | на телефоне разрешить отладку; если вопрос не появляется, в «Для разработчиков» нажать «Отозвать авторизацию отладки по USB» и переподключить |
| `INSTALL_FAILED_USER_RESTRICTED` (Xiaomi) | включить «Установка через USB» в «Для разработчиков» |
| `adb` пишет `daemon not running` | `adb kill-server`, потом `adb start-server` |
| scrcpy показывает чёрный экран | на телефоне снять блокировку, приложения банков и DRM не транслируются, игра транслируется |
| меню «Отладка» не открывается | тапы медленнее трёх секунд на пять; либо стоит релизная сборка (магазинная) |
