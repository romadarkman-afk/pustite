# Настройка русской озвучки

Генератор использует ElevenLabs v3 для сюжетных реплик и коротких голосовых реакций жителей. Он создаёт семь голосовых профилей, добавляет эмоциональные теги и сохраняет аудио в `game/assets/voice`. Реакции жителей являются короткими вздохами, испугом и другими звуками голоса. Они заменят синтетические писки, которые играют, пока файлов реакции нет.

В пакете 309 сюжетных реплик и 224 игровые реакции. Бесплатный план даёт 10 000 кредитов и 3 пользовательских голоса. Этого не хватит для семи профилей и полного пакета. Starter у ElevenLabs указан как 30 000 кредитов и 10 пользовательских голосов, стандартная цена $6 в месяц. Условия и промоакции могут меняться. [Тарифы](https://elevenlabs.io/pricing) · [слоты голосов](https://elevenlabs.io/docs/help-center/account/general/how-many-voice-slots-do-i-get-per-tier-and-how-can-i-increase-it).

Перед генерацией скрипт читает лимит кредитов и голосовые слоты через API. Если доступного лимита или слотов мало, он прекращает работу до создания голосов и аудиофайлов. Расход считается с запасом 15 процентов. Скрипт не меняет тариф и не покупает кредиты.

## Подключение

1. Создай API key ElevenLabs с доступом к Voice Design и Text to Speech.
2. В GitHub открой **Settings → Secrets and variables → Actions**.
3. Добавь repository secret с именем `ELEVENLABS_API_KEY`. Сам ключ в чат не отправляй.
4. Открой **Actions → Полная русская озвучка → Run workflow** и выбери `main`.

Генератор сохраняет профили в `docs/voiceover-voices.json`, а готовые части и контрольные суммы в `docs/voiceover-manifest.json`. При повторном запуске проверенные файлы пропускаются. После успешного завершения Android workflow автоматически собирает APK.

Старый Gemini workflow удалён. Секрет `GEMINI_API_KEY` новый генератор не читает.
