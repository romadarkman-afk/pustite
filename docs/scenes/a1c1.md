# Глава 1 «Стук»: сценарий по кадрам

Глава учит игре без правил на экране. Первый стук звучит не позже 20 секунд после «Играть»: сцена у реки идёт 8–12 секунд, каждый кадр листается тапом через секунду. Вся глава занимает 8–12 минут.

Игровые условия главы не менялись: 5 жителей, 1 упырь, 2 дома по 2 места, 3 ночи. Глава начинается сразу со стука (cold open), цели показываются после первой ночи.

## Сцена 1. Река

| Пункт | Содержание |
| --- | --- |
| Место и время | Берег реки, сумерки |
| Персонажи | Игрок, голос с того берега, Марина (перевозчица) |
| Эмоция | Тревога. Голос знакомый, хотя здесь игрока никто не знает |
| Кадр 1 | `assets/scenes/river.jpg` (пока нет: сцена идёт поверх посёлка с затемнением). Медленный наезд 1.0 → 1.1, туман |
| Реплики | «Сумерки. Дорога кончается у реки. Дальше только паром.» Голос с того берега: «{имя игрока}!» |
| Звук | Тишина, затем фон реки (amb_river), на 1,6 с далёкий зов (call_far) |
| Кадр 2 | Портрет Марины крупно, ночь, туман |
| Реплика | Марина: «Не отвечай. Оно запоминает голоса.» |
| Действие игрока | «Промолчать» или «Отозваться». Выбор пишется в журнал партии (CHOICE) |
| Последствия | Отозвался: Марина меньше доверяет игроку и днём говорит: «Я просила не отвечать на тот берег. Теперь оно знает твой голос.» |
| Реализация | Scenes.river, DoorScreen._start_knocks, Director.river_answered |

## Сцена 2. Первая ночь

| Пункт | Содержание |
| --- | --- |
| Место и время | Изба игрока, полночь |
| Кадр | `assets/scenes/door_inside_night.jpg` (пока нет). Текст: «Перевозчица гасит фонарь. До деревни идёте молча.» (или вариант после ответа на зов), затем «Ночь. В дверь стучат.» |
| Звук | Тишина, ночной фон, на 2,4 с стук. После стука за дверью слышно дыхание (breath) |
| Кто стучит | Двое. Через раз один из них упырь, но в первую ночь он сыт и никого не тронет |
| Действия игрока | Осмотреть (2 раза), спросить «Кто там?» (1 раз за ночь), впустить, не открывать |
| «Кто там?» | Человек почти всегда отвечает по делу: называет дом, куда собирался днём, или честно говорит, что передумал. Упырь по делу отвечает реже, чаще: «Открой, потом расскажу. Холодно.» |
| Если молчишь | Через 5,5 с стучат снова, до трёх раз |
| Реализация | DoorScreen (ask_who, _idle_knock), Director.door_answer, Match.cold_open |

## Сцена 3. Первое утро: три исхода

| Исход | Кадры |
| --- | --- |
| Впустил человека | Портрет гостя на рассвете: «Утро. {гость} спит у печи под твоим тулупом.» Гость: «Я не забуду, кто открыл мне ночью.» Гость становится союзником: доверие к игроку выше |
| Впустил упыря (или, реже, человека, который ночью вставал) | Ночь: «Под утро скрипит половица. Кто-то стоит у твоей лавки.» Звук половицы. «За стеной кашляет сосед. Шаги отходят к печи.» Утро: «{гость} говорит, что ночью не вставал.» Сцена бывает и с человеком (в 25% случаев), поэтому это подозрение, а не доказательство |
| Не открыл | «На снегу у двери следы. Кто-то долго стоял на пороге.» Если стучавший выжил: «Я стучал. Дверь так и не открылась. Я запомню.» Если нет: «Следы обрываются у дороги.» Дальше реакция близких по TASK-010 |

Реализация: Scenes.first_morning, MorningScreen.morning_scene.

## Сцена 4. День

Знакомство с жителями. Цель главы «выслушай одну историю» даёт третий осмотр у двери. В первый же день кто-то из жителей обязательно обещает игроку открыть ночью: так игрок узнаёт про обещания. Игрок может пообещать в ответ из карточки жителя.

## Сцена 5. Вторая и третья ночь, итог

Обычные ночи. Если кто-то погиб, а его близкий жив, утро начинается со сцены утраты этого близкого (TASK-014). На итоге главы карточка «Их память»: 2–4 строки о том, что жители запомнили.

## Картинки для сцен (пока нет, сцены работают без них)

- `assets/scenes/river.jpg` — берег в сумерках, паром, туман, фонарь в руке перевозчицы.
- `assets/scenes/door_inside_night.jpg` — дверь избы изнутри ночью, полоса света под дверью, тень ног в щели.
- `assets/scenes/grief_0.jpg` … `grief_11.jpg` — крупные планы предметов утраты (чашка, гвозди, доска с именами и т. д.).

| Река, кадр 3 (Марина) | без изменений: река идёт под выбор |
