## TASK-054: звуковой бюджет

Лимит самотеста `--sound`: 6 МиБ. В тесте должно оставаться не менее 2,5 МиБ, значит зарегистрированные звуки занимают максимум 3,5 МиБ.

| Состояние | Зарегистрированные звуки | Свободно из 6 МиБ |
|---|---:|---:|
| До перекодирования | 8 261 596 байт, 7,879 МиБ | лимит превышен |
| После перекодирования в ветке `pack-1` | 2 671 666 байт, 2,548 МиБ | 3 619 790 байт, 3,452 МиБ |

После перекодирования в папке `game/assets` лежит 9 157 783 байта аудиоисходников. Старые WAV сохранены в репозитории. Android export исключает `*.wav`, неиспользуемый `assets/music/menu.ogg` и тестовые `tests/fixtures/*.cfg`; игра загружает OGG-версии. Так исходники остаются доступными, а APK собирается из зарегистрированных ресурсов.

## TASK-070: производительность погоды

Что сделано в коде:

- Игра считает кадры окнами по секунде. Если 5 окон подряд идут ниже 25 кадров в секунду, включается упрощённая графика и показывается сообщение. Один раз за установку: если игрок потом выключит режим руками, игра его не вернёт. Одиночная пауза (загрузка, сворачивание) весит не больше полусекунды, сворачивание и потеря фокуса обнуляют серию.
- Упрощённая графика: частиц вдвое меньше (туман 7 вместо 14, пыль 12 вместо 24, эмиттеры погоды вдвое), тени ламп выключены, ночной цветовой слой выключен, тени облаков не рисуются, трава стоит без качания, иней и влага на фигурах выключены. Шейдер земли (снег, мокрый блеск, лужи) остаётся: он заменил прежнюю отрисовку кодом. Цвет стекла фонаря героя тоже остаётся: это выбранная косметика, шейдер на одной фигуре.
- В отладочной сборке в левом верхнем углу счётчик: `FPS 58  мин 41`. Первое число за последнюю секунду, второе худшая секунда с начала текущего экрана. APK из CI собирается командой `--export-debug`, поэтому счётчик есть на телефоне. В релизной сборке его нет.

Замер на слабом телефоне Влади не выполнен: у меня нет доступа к телефону. Порядок: поставить APK, в настройках выключить упрощённую графику, открыть главу, дойти до дня 2 и в ночь, записать «мин» с экрана дня и экрана двери. Потом повторить с включённой упрощённой графикой.

| Сезон | Глава | Профиль | Модель телефона | Кадры день, мин | Кадры дверь, мин | С упрощённой графикой | Записано |
|---|---|---|---|---:|---:|---:|---|
| Лето | a1c3 | `river_storm` (дождь) | | | | | |
| Осень | a2c1 | `rain_swollen_river` (дождь, лужи) | | | | | |
| Зима | a3c1 | `blizzard` (метель, снег) | | | | | |
| Весна | a4c1 | `thaw_rail_fog` (туман, дождь) | | | | | |

Лимиты из кода, которые можно проверить без телефона: до 60 частиц на эмиттер; траву не больше 150 пучков (`MAX_TUFTS`); 6 длинных звуковых потоков; тест `--weather` на 12 главах и 4 сезонах.

## TASK-057–059: свет и ночной grade

| Изменение | Дополнительные файлы в APK | Ограничение |
|---|---:|---|
| `LightHalo` | 0 изображений; градиентная текстура строится один раз в памяти | аддитивный 2D-спрайт на каждый источник |
| Ночной цветовой grade | один shader-ресурс, меньше 1 КиБ исходного кода | полноэкранный проход, отключается настройкой |
| Упрощённая графика | 0 | 7 туманных и 12 пылевых частиц вместо 14 и 24; тени ламп выключены |
| A/B стенд | только скрипт и сцена в каталоге tests | не включать в игровой экран и меню |

Сравнение FPS на телефоне и эмуляторе ещё не выполнено. Порядок ручного замера и незаполненные строки устройств: `docs/lighting-benchmark.md`. Godot Compatibility не использует HDR для 2D, а уровни glow работают в упрощённом варианте, поэтому цифровой замер нужен на конкретных Android GPU.

Перекодировано:

- `menu_theme.ogg` и `river_theme.ogg`: стерео, 128 кбит/с.
- `amb_day.ogg`, `amb_night.ogg`, `amb_dusk.ogg`, `amb_river.ogg`: моно, 64 кбит/с.
- `human_cry_m.ogg` и `upyr_cry.ogg`: моно, 96 кбит/с.
- Шесть коротких стереоэффектов: моно, 96 кбит/с.

Для прослушивания подготовлены: тема меню, тема реки, ночной фон, крик упыря и крик человека. Задача остаётся на проверке Влади. Цифры APK и результат `--sound` требуют подтверждения CI на Godot 4.6.
